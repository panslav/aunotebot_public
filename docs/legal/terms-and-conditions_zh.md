## 1. 当事方与定义

1.1. 本条款适用于 Telegram 机器人 Telenota 的使用；该服务此前以 AUNotebot 名称开发和记录（下称“服务”）。

1.2. 服务由位于西班牙的私人所有者运营（下称“所有者”）。

1.3. “用户”指访问或使用本服务的任何个人。

1.4. “内容”包括提交到本服务或通过本服务生成的任何文本、媒体、链接、元数据、标签、提醒、摘要、转写、翻译、生成音频或其他输出。

1.5. “AI 功能”指使用第三方人工智能提供商的功能，包括转写、OCR、摘要、标签、翻译、Recall/搜索答案、链接描述和文本转语音。

## 15. 管理跟踪披露

15.1. 本服务记录管理用户索引（`id`、`handle`），用于运营支持。

15.2. 本服务记录机器人操作日志，字段可能包括 `id`、`moment`（UTC）、`action_type` 和技术来源标记。

15.3. Telegram Bot API 轮询不会向本服务暴露最终用户 IP 地址；因此类似 IP 的字段可存储为 `unavailable_via_telegram_bot_api`。

15.4. 本服务记录分享关系边，字段可能包括 `id`、`source`、`target`、`action_type`（`shr` 表示分享笔记，`asgn` 表示分配任务），并可维护运营导出或镜像，用于图谱、诊断和防止滥用。
