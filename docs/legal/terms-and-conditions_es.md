# Condiciones de uso (bot Telenota)

---

Última actualización: 4 de junio de 2026

## 1. Partes y definiciones

1.1. Estas Condiciones regulan el uso del bot de Telegram Telenota, desarrollado y documentado anteriormente como AUNotebot (el "Servicio").

1.2. El Servicio es operado por un propietario privado ubicado en España (el "Propietario").

1.3. "Usuario" significa cualquier persona que acceda al Servicio o lo use.

1.4. "Contenido" incluye cualquier texto, medio, enlace, metadato, etiqueta, recordatorio, resumen, transcripción, traducción, audio generado u otro resultado enviado al Servicio o generado mediante él.

1.5. "Funciones de IA" significa funcionalidades que usan proveedores externos de inteligencia artificial, incluidas transcripción, OCR, resumen, etiquetado, traducción, respuestas de recuerdo/búsqueda, descripciones de enlaces y texto a voz.

## 2. Aceptación y elegibilidad

2.1. Al pulsar **Aceptar**, usar `/start` o seguir usando el Servicio después de que se muestren estas Condiciones, confirmas que las has leído y aceptado.

2.2. Si no aceptas estas Condiciones, no debes usar el Servicio.

2.3. Declaras que tienes capacidad legal para aceptar estas Condiciones y usar el Servicio.

2.4. Si usas el Servicio en nombre de otra persona u organización, confirmas que estás autorizado para hacerlo.

3.1. El Servicio ayuda a crear, gestionar, buscar, compartir y asignar notas, tareas, borradores, recordatorios, etiquetas y contenido relacionado en Telegram.

3.2. El Servicio puede usar operaciones asistidas por IA, incluidas transcripción, OCR, resumen, etiquetado, traducción, respuestas de recuerdo/búsqueda, descripciones de enlaces y texto a voz.

3.3. Las funciones se ofrecen a discreción del Propietario y pueden variar según usuario, idioma, región, comportamiento del cliente de Telegram, política de plataforma o disponibilidad técnica.

3.4. El Servicio puede generar o transformar partes del Contenido. Los resultados de IA pueden ser inexactos, incompletos, retrasarse o no ser adecuados para un fin concreto.

3.5. El Servicio no está diseñado para emergencias, registros legalmente obligatorios ni situaciones en las que una pérdida, retraso o inexactitud pueda causar daños graves.

12.9. El bot puede incluir una opción de autoservicio para eliminar datos de cuenta propios del bot. ## 15. Divulgación de seguimiento administrativo

15.1. El Servicio registra un índice administrativo de usuarios (`id`, `handle`) para soporte operativo.

15.2. El Servicio registra logs de acciones del bot con campos como `id`, `moment` (UTC), `action_type` y marcadores técnicos de origen.

15.3. El polling de Telegram Bot API no expone direcciones IP de usuarios finales al Servicio; por tanto, campos similares a IP pueden almacenarse como `unavailable_via_telegram_bot_api`.

15.4. El Servicio registra relaciones de compartir con campos como `id`, `source`, `target`, `action_type` (`shr` para compartir notas, `asgn` para asignación de tareas) y puede mantener exportaciones o espejos operativos para gráficos, diagnóstico y prevención de abuso.
